# Der alte Deich – Hörbuch

Ein Roman, gelesen von Matthias. Für meinen Vater, zum 90. Geburtstag am 4. November 2026.

Die Hörbuch-Seite liegt unter GitHub Pages; sie wird aus diesem Repository (Zweig `main`) veröffentlicht.

- `index.html` – die Seite (wird aus `page.tpl.html` und `tracks.json` mit `python3 build_page.py` erzeugt)
- `audio/` – die 20 Teile als MP3 (320 kbit/s)
- `fonts/`, `img/` – Schrift (EB Garamond, SIL Open Font License) und Cover

Wichtig: Die Adresse dieser Seite ist als QR-Code im gedruckten Buch. Repository nicht umbenennen oder löschen.
